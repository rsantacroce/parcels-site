Asset list

Every model the game could use in place of its procedural geometry. Each card has the file name, the real-world size and a prompt for Meshy Text to 3D. Copy prompt includes the shared style line, so you can paste it as it is.

How to generate and hand back a model
  1. Open Meshy → Text to 3D, paste a prompt, generate, and pick the best preview.
  2. Refine it (texture), then download as GLB.
  3. Name it as shown on the card (for example power/coal_plant.glb).
  4. Scale: 1 unit = 1 metre, a map tile is 10 × 10 m. The origin goes at the centre of the footprint on the ground, the front faces −Z, and nothing may overhang the footprint.

Or do it all from the repo with the API:

export MESHY_API_KEY=msy_...
python3 tools/meshy.py --list
python3 tools/meshy.py coal_plant water_tower
python3 tools/meshy.py --group parks
python3 tools/meshy.py --all --skip-existing
